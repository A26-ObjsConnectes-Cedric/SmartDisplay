# À propos du projet SmartDisplay
Prototype d'objet connecté réalisé dans le cadre du cours Objets connectés —- Mandat 08 du cahier des charges **Projet Ariane**.

## Objectif du projet
Recevoir un message depuis Grafana (via Node-RED et MQTT), l'afficher sur un écran OLED de l'ESP32, distinguer les messages NORMAL/ALERTE, publier un accusé de réception et journaliser l'historique dans InfluxDB/Grafana.
